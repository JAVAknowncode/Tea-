Syntax Every .tea script must start with the mandatory bootstrap header on the first line: import.tea.util;. Immediately following this, you can import custom modules enclosed in angle brackets where the name ends with an l (such as ;, ;, ;, or ;). Afterward, you write your core logic using structured variable assignments (variable variable_name = value;), I/O output commands (iol.print();), or math operations like mathl.power(). Any import failing to end with an l is automatically rejected by the compiler.

How to Run Open your terminal inside your project folder and ensure Python is installed. Execute your .tea script by passing it to the core interpreter: python tea_runner.py app.tea. Alternatively, you can package your runner and scripts into a standalone executable (tea.exe) using PyInstaller to run your applications directly from your dist folder without requiring a manual Python environment.
